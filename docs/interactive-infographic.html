Hardware Biometric Authentication

Unlocks your encrypted vault in seconds using your fingerprint, face, or security key across Windows, macOS, Linux, and Android.

🪟 Desktop Platforms

Windows: Native Windows Hello (DPAPI / WebAuthn).
macOS: Touch ID via native platform authenticator.
Linux: Pluggable Authentication Module via fprintd.

📱 Android Isolated Bridge

Because Android WebView blocks biometrics inside Obsidian, MySecret routes to a companion PWA on Cloudflare Pages using ephemeral ECDH P-256 key exchange. Your vault ID never leaves the app.

BIP-39 Deterministic Mnemonic Recovery

Like a Bitcoin hardware wallet: 24 English words generated from 256 bits of cryptographic entropy guarantee you can recover your vault even if you forget your master password.

1. abandon 2. ability 3. abstract ... 24. zebra

Derived using HKDF-SHA256 and validated against the official 2048-word BIP-39 English dictionary with SHA-256 checksum verification. 100% offline, zero third-party dependencies.
